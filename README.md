A University of Central Florida senior design project, sponsored by the Virtaul Experience Research Accelerator (VERA).
Aims to provide VR researchers with a Unity toolkit, which allows easy enabling of locomotive and mobility accessibility options.

NOTE: Project has been migrated; this is an archive of the progress at the end of the senior design project.
The toolkit has been formally introduced into the VERA suite of tools, and work continues on developing those tools in that repo.
This repo is no longer supported, and functionality cannot be garunteed. For a more functional toolkit, see the official VERA suite.
